> 运行演示：`python learn/lesson6_dpo.py`
> 核心认知：SFT 教模型"说什么"，DPO 教模型"在两个说法里更喜欢哪个"。

## 原理：一张对比考卷 + 一条防跑偏公式

**考卷**（`dataset/dpo_smoke.jsonl`）：每道题 = 同一问题 + `chosen`（好答案）+ `rejected`（坏答案）。没有人写"标准答案"，只有相对好坏。

**损失**（`train_dpo.py:34-50`）：

```
间距 = [logP(好) - logP(坏)]当前模型 - [logP(好) - logP(坏)]参考模型
loss = -log sigmoid(beta × 间距)
```

- 训练开始时当前模型 = 参考模型 → 间距 = 0 → loss = ln(2) = 0.693（**看你训练日志的第一步，必然是 0.69 左右，数学必然**）
- 间距 > 0（比参考更偏好"好"）→ loss 下降；间距 < 0 → loss 上升
- 参考模型是起点的冻结拷贝（:186-188），作用 = "原地踏步记 0 分"，防止模型靠全面跑偏刷分

## 一个本课实测的震撼发现

我对比了官方 `out/full_sft_768.pth` 和 `out/dpo_768.pth` 的权重：**最大差异只有 3.8e-6——小于半精度浮点的最小刻度**。官方 DPO 默认 lr=4e-8，训练后的权重改动小到几乎被存储精度抹平。这就是"DPO 是拧最后几圈螺丝"的具象化。

所以演示用的是本课亲训的加大力度版（lr=5e-6，仍完好没崩）。实测效果（24 对答案）：相对间距均值 +6.98、67% 样本偏好向"好答案"移动、代回损失公式平均 0.619（从 0.693 起步）。

## 实验三：亲手 DPO（约 2 分钟）

```bash
cd /app/zdf/minimind/trainer
python train_dpo.py --epochs 1 --batch_size 4 --learning_rate 5e-6 \
  --data_path ../dataset/dpo_smoke.jsonl \
  --from_weight full_sft --save_weight dpo_6b \
  --log_interval 50 --num_workers 4
```

**已验证**：500 步约 1.5 分钟，loss 从 0.69 降到 ~0.32-0.45。
观察：每个 batch 要过**两个模型**（参考模型 + 当前模型）——DPO 训练慢就慢在这，显存也要双份。

## 验收自测

1. DPO 考卷和 SFT 考卷的本质区别是什么？
2. 为什么 DPO 第一步 loss 必然 ≈ 0.693？
3. 参考模型起什么作用？没有它会怎样？
4. beta 调大/调小分别什么效果？
5. 为什么 DPO 的学习率要比 SFT 小 250 倍？

<details>
<summary>自测答案（先自己答，再展开）</summary>

1. SFT 每题一个"标准答案"（模仿）；DPO 每题两个答案只标相对好坏（偏好）。
2. 起点时当前模型=参考模型，间距恒为 0，-log sigmoid(0) = ln 2 ≈ 0.693。
3. 提供"零点"：间距是相对参考模型算的，防止模型用整体跑偏（比如把所有答案概率都压低）来"拉开"差距。没有它，优化会退化且极易灾难性遗忘。
4. beta 大→间距被放大、损失梯度对"远离参考"惩罚重，模型贴着参考动弹；beta 小→放任跑远，容易过冲、语言退化。
5. 偏好信号是"相对比较"，梯度天然带噪声；且模型已经过多轮打磨，任何大步子都可能毁掉语言能力（对齐税）。实测官方权重改动 < 4e-6。

</details>
