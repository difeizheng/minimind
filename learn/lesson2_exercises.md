## 代码导读：model/model_minimind.py 十分钟走读

数据从上到下流过五个关卡（行号为 model_minimind.py 里的位置）：

| 关卡 | 代码位置 | 干什么 |
|---|---|---|
| 1. 查字典 | :214 `embed_tokens(input_ids)` | 每个 token 编号 → 查表得到 768 维向量 |
| 2. 开会（注意力） | :91-134 `Attention` | 每个字回看前文，按相关性抄别人的信息 |
| 3. 回房消化（MLP） | :136-146 `FeedForward` | 三个矩阵变换+门控，模型的"知识仓库" |
| 4. 以上×8 层 | :178-194 `MiniMindBlock` | 每层=开会→残差→消化→残差，理解逐层加深 |
| 5. 下赌注 | :241,248 `lm_head` | 768 维向量 → 6400 个分数 → softmax=赌注分布 |

第 1 课的"对答案"就发生在 :251-252：`logits[:-1]` 对齐 `labels[1:]` 算交叉熵——loss = -ln(正确字的赌注概率)。

三个工程细节先混个脸熟，**别陷进去**：
- **RoPE**(:62-84)：给每个字盖"位置邮戳"，注意力才知道谁前谁后；
- **RMSNorm**(:50-60)：把每层输出拉回正常数值范围，防止越算越爆；
- **MoE**(:148-176)：把 MLP 换成"多位专家会诊"的进阶版（训练日志里的 aux_loss 就是它的路由损耗，以后讲）。

## 验收自测（能答出来就算第 2 步过关）

1. 用一句话说出模型的三段式流水线。
2. 为什么问"我爱秋?"时，赌注最高的不是"天"而是"一"？这说明预训练模型学到的是什么？
3. 注意力的"因果掩码"(:129 的 -inf 上三角)是干嘛的？去掉会怎样？
4. 70% 的参数在 MLP 里，这个事实说明了什么？
5. 训练前后，模型改变的是什么？不变的是什么？

<details>
<summary>自测答案（先自己答，再展开）</summary>

1. 查字典（字→向量）→ 8 层"开会+消化"（向量一路加工）→ 下赌注（向量→6400 个概率）。
2. 说明它学到的是**训练语料的统计规律**而非人类常识——它对很多可能的续写都保留赌注（"我爱的秋天""我爱秋天的…"等模式混在一起），64M 的小模型 + 小语料下分布比较平。模型越大、数据越多，分布越尖锐、越符合直觉。
3. 因果掩码让每个位置只能看到**之前**的字，不能偷看未来。去掉的话训练时模型直接"抄答案"（下一个字就在眼前），什么也学不到，生成时也无从谈起。
4. 模型的"知识/记忆"主要存在 MLP 的矩阵里，注意力主要负责在字与字之间搬运信息。这也是"微调能改变模型知识"的物理基础——动的主要就是这些矩阵。
5. 改变的是 6400 万个参数的**数值**（结构、连接方式完全不变）；数值变了，每个位置的赌注分布就变了——学习就是"重塑赌注"。

</details>
